Download path

With this setting you can specify the name of downloaded files.
A preview of your file name is shown below the input.
Variables can be used to add extra data like the username of the author and more.
Click the Variables button to use them.

With this setting you can specify the location and name of downloaded files.
A preview of your path is shown below the input.
The file location can be changed relative to your downloads folder by using "/".
For example "bluesky/test" would produce the file "test.mp4" in the folder "downloads/bluesky".
Variables can be used to add extra data like the username of the author and more.
Click the Variables button to use them.
